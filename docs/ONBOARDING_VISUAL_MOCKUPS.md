## Accessibility Features

### Screen Reader Announcements

```typescript
// Example ARIA labels and announcements

<div role="progressbar"
     aria-valuenow={currentStep}
     aria-valuemin={1}
     aria-valuemax={5}
     aria-label={`Step ${currentStep} of 5: ${stepName}`}>

<button aria-label="Information about why we need your Social Security Number">
  <InfoIcon />
</button>

<div role="status" aria-live="polite">
  Progress saved automatically
</div>

<input
  aria-label="First name"
  aria-required="true"
  aria-invalid={hasError}
  aria-describedby="first-name-error"
/>
```

### Keyboard Navigation

```
Tab Order:
1. Skip button
2. Progress indicator (focusable for screen readers)
3. First form field
4. Info tooltip (if present)
5. Second form field
6. ...
7. Back button
8. Continue button

Keyboard Shortcuts:
- Tab: Next field
- Shift+Tab: Previous field
- Enter: Submit/Continue
- Escape: Close tooltip/modal
- Alt+S: Skip step (if available)
- Alt+B: Go back
```
