# CPFI (Credit Pro & Financial Intelligence) Mobile App Assets

This directory contains all the visual assets for the mobile app.

## Required Assets

### App Icons
- `icon.png` - Main app icon (1024x1024px, PNG)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024px, PNG)
- `notification-icon.png` - Push notification icon (96x96px, PNG, white on transparent)
- `favicon.png` - Web favicon (48x48px, PNG)

### Splash Screen
- `splash.png` - Splash screen image (1284x2778px recommended, PNG)

### Sound Assets
- `sounds/notification.wav` - Push notification sound (optional)

## Design Guidelines

### Brand Colors
- Primary: #3B82F6 (Blue)
- Secondary: #10B981 (Green)
- Accent: #8B5CF6 (Purple)
- Background: #FFFFFF
- Text: #1F2937

### Icon Requirements
- App icon should be square with no transparency
- Use the CPFI (Credit Pro & Financial Intelligence) logo centered
- Include appropriate padding (20% of icon size)

### Splash Screen
- Center the logo vertically
- Use brand primary color as background
- Include "CPFI (Credit Pro & Financial Intelligence)" text below logo
- Tagline: "AI-Powered Credit Repair"

## Asset Generation

Use the following tools to generate all required sizes:
- https://www.appicon.co/ - Generate all icon sizes
- https://apetools.webprofusion.com/ - Splash screen generator

## Store Assets (Not in this directory)

For app store submission, you'll also need:

### iOS App Store
- Screenshots (6.5" display): 1284x2778px
- Screenshots (5.5" display): 1242x2208px
- App Preview video (optional): 1920x1080px

### Google Play Store
- Feature graphic: 1024x500px
- Screenshots: 16:9 or 9:16 ratio
- Promo video thumbnail: 1024x500px
